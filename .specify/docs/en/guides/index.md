# TDK Guides

> Pick the guide that matches your situation.
> `/tdk-*` commands run in the Claude Code chat, not in a terminal.

## Start Here

| Situation | Open | Why |
|---|---|---|
| New machine or freshly cloned repo | [Setup Guide](setup/setup-guide.md) | Install TDK and confirm `/tdk-*` commands appear |
| New project, broad feature, or vague idea | [Epic Start Guide](scenarios/00-epic-start-guide.md) | Turn an epic into child feature specs |
| One clear child feature or seed to build | [Child Feature Implementation](scenarios/01-child-feature-implementation.md) | Go straight to spec, plan, implement |
| Not sure which workflow fits | [Scenario Catalog](scenarios/scenario-catalog.md) | Compare common scenarios before choosing |
| New to TDK terminology | [Glossary](concepts/glossary.md) | Understand terms used across guides |
| Looking up one command | [Skills Guide](skills-guide.md) | Syntax, modes, inputs, and outputs |

## Default Project Flow

```text
/tdk-discovery
-> /tdk-epic-prd
-> /tdk-epic-hld
-> /tdk-task-breakdown
-> child /tdk-specify
-> /tdk-clarify
-> /tdk-plan
-> /tdk-implement
```

If the work is already one small clear feature, skip the epic commands and start at `/tdk-specify`.

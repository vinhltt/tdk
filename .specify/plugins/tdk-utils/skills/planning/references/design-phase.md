# Design Phase

## Purpose

Make architecture decisions and define data models.

## Steps

1. Extract entities from spec → data-model.md
2. Define API contracts → contracts/
3. Plan file structure based on framework
4. Identify dependencies and risks

## Output

- `data-model.md` - Entities, relationships, validation
- `contracts/` - API specifications
- `quickstart.md` - Integration scenarios

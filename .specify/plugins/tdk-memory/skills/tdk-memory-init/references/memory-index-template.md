## Routing Rules

| Content Type | Target File Pattern | Template |
|---|---|---|
| Entity / table definition | `data-model/{table-name}.md` | `data-model-template.md` |
| Service / API method | `domains/{domain}/services.md` | `services-template.md` |
| Business logic / validation rule | `domains/{domain}/business-rules.md` | `business-rules-template.md` |
| Screen / UI component | `screens/{module}/{name}.md` | `screen-template.md` |
| Multi-screen user journey | `screen-flows/{flow-name}.md` | `screen-flow-template.md` |
| Complex multi-step flow (domain-specific) | `domains/{domain}/flows/{name}-flow.md` | `flow-template.md` |
| Cross-domain flow | `shared-flows/{flow-name}.md` | `flow-template.md` |

## Templates

All templates: `.specify/templates/memory/`
- `services-template.md` — per-service entry with section anchors
- `data-model-template.md` — table definition with fields, relations, indexes
- `business-rules-template.md` — per-rule with condition, action, example
- `screen-template.md` — screen doc with scenarios, API calls, UX flow, components
- `screen-flow-template.md` — multi-screen journey with steps, branch conditions
- `flow-template.md` — complex API/business flow with steps, error handling, dependencies

## Templates

All templates: `.specify/templates/memory/`
- `memory-readme-template.md.tpl` — root memory control guide
- `arc42-readme-template.md.tpl` — arc42 read-model guide
- `arc42-summary-template.md.tpl` — non-binding arc42 section summary
- `services-template.md.tpl` — per-service entry with section anchors
- `data-model-template.md.tpl` — table definition with fields, relations, indexes
- `business-rules-template.md.tpl` — per-rule with condition, action, example
- `screen-template.md.tpl` — screen doc with scenarios, API calls, UX flow, components
- `screen-flow-template.md.tpl` — multi-screen journey with steps, branch conditions
- `flow-template.md.tpl` — complex API/business flow with steps, error handling, dependencies
- `integration-contract-template.md.tpl` — typed external or internal contract
- `operations-runbook-template.md.tpl` — operational procedure and rollback
- `quality-requirement-template.md.tpl` — binding quality, security, privacy, compliance, NFR facts
- `decision-record-template.md.tpl` — durable decision record / ADR
- `risk-debt-template.md.tpl` — risk, technical debt, or assumption record
- `report-spec-template.md.tpl` — report, dashboard, or export specification
- `capabilities-template.md.tpl` — durable business capability
- `stakeholders-and-roles-template.md.tpl` — stakeholder, actor, role, permission profile
- `glossary-template.md.tpl` — ubiquitous language term
- `decision-table-template.md.tpl` — decision matrix for rules
- `state-machine-template.md.tpl` — state lifecycle and transitions

Optional typed folders are lazy. Do not create empty category folders during
fresh init; create a folder only when writing the first file for that route.

## Embedded Brainstorming (Reasoning Mode)

**Mode:** Embedded -- reasoning technique only.
**DO NOT** call brainstorm.py. **DO NOT** create separate brainstorm files.
Output goes directly into the host command's destination artifact.

**Technique per decision point:**
1. Identify 2-3 viable approaches
2. Evaluate each: Pros, Cons, Best-For context
3. Apply YAGNI/KISS/DRY lens to recommend one

## Sequential Thinking

**Technique:** Apply structured step-by-step reasoning:
1. Define the problem/decision clearly
2. List all relevant factors
3. Evaluate systematically (scoring or ranking)
4. Validate: check for circular logic or missing considerations
5. Conclude with explicit recommendation
